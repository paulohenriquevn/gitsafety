# Milestone M5 — Histórico (`--history`) — linha de chegada da V1

## Definition of done (do ROADMAP.md)

- [x] `gitsafety scan --history` percorre o histórico e reporta commit, autor e data
- [x] Reusa o **mesmo** matcher do scan de arquivos — sem segundo motor de detecção
- [x] Teste de integração com segredo introduzido e depois removido: ainda é detectado
- [x] Repositório sem commits → sem crash

## O que a descoberta mudou

O comando que o gitleaks usa (`git log -p --full-history --all --diff-filter=tuxdb`) **não
enxerga** um segredo colado ao resolver um conflito de merge — medido: 0 achados onde há 1
real, com o valor ausente de ambos os pais. `log -p` não emite diff de merge por padrão.
Usamos `--diff-merges=first-parent`, que acha, ao mesmo custo (0,113 s contra 0,115 s).

Foi a pergunta obrigatória "o que o comando escolhido **não** enxerga?" que revelou isso —
checkpoint que existe no plano por causa das cinco rodadas de review do M4.

## O que o review pegou, e que a suíte não pegava

**Fail-open no hook.** Uma linha `*.env -diff` no `.gitattributes` fazia o git emitir
`Binary files differ`, e o commit da credencial **passava**. O mesmo com byte NUL e com
driver `textconv`. As três são configuráveis pelo próprio repositório. `--no-ext-diff`
sozinho era meia defesa; agora `--text` e `--no-textconv` também, nos dois caminhos.

**Arquivo em latin-1** derrubava o comando inteiro com `UnicodeDecodeError` de dentro do
subprocess. `scanner._read_text` já usava `errors="replace"` desde o M0 e documentava o
motivo — a defesa não tinha sido levada à fronteira do git.

A raiz de ambos passar despercebido: `test_same_matcher_as_file_scan` afirma o invariante
certo (`scan_path ⊆ scan_history`) com uma fixture **ASCII pura**, que não consegue disparar
nenhuma das classes de entrada que o quebram. É a mesma lição do M4 — o teste escrito por
quem escreveu o código herda o viés do código.

## Divergências honestas registradas

| Item | Situação |
|---|---|
| Contagem de "commits" | O plano dizia "em quantos commits a ocorrência aparece". Diff não sabe isso; o campo mede **introduções**. Corrigido no código, no teste e no docstring |
| Custo | Benchmark sintético dava 0,37 s / 5.000 commits e mentia. Real: ~6 s no próprio repositório. Backlog § B3 |
| Custo de `--text` em binário | 30 MB = 5,67 s, 416 MB de pico. README qualificado, backlog § B5 |
| Reflog | `--history` não alcança commit reescrito. README § Histórico + backlog § B4 |
| C-quoting de caminho acentuado | `ignore:` falha em silêncio para nome com acento. MEDIUM aberto — direção da falha é ruído, não cegueira |
