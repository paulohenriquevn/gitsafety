## Desvio do fluxo padrão, declarado

`cycle-release` prevê PR `develop → main` com aprovação humana. **Não foi possível
abrir o PR:** o `gh` está autenticado como `usetheodev`, enquanto o repositório é
`paulohenriquevn/gitsafety` — `gh pr create` retorna
*"must be a collaborator (createPullRequest)"*, e `gh repo edit` retorna HTTP 404. O
`git push` funciona porque a chave SSH é do dono; a API do GitHub não.

O corte foi feito por **merge manual `develop → main` + tag semver**, caminho
explicitamente previsto em `rules/git-safety.md § 1`
(*"manual ou via PR de release"*), com autorização explícita do operador para
executar o merge.

Nenhum commit foi feito diretamente em `main`: ela avançou por fast-forward para o
estado já revisado de `develop`. O hook `validate-command.sh` não foi contornado —
`main` nunca foi checada out.
